NullAway

Java · Static Analysis · Open Source · Compiler · JSpecify

Uber의 Java nullability 정적 분석 도구 NullAway의 기능을 확장했습니다. 대학원 연구부터 졸업 후까지 프로젝트에 참여하며 generic type 분석과 외부 라이브러리 및 JDK의 nullability 정보를 NullAway에서 활용하기 위한 기능을 구현했습니다.

Generic Method Type Argument Analysis

  • Generic method 호출에서 type argument의 nullability 분석 기능 구현
  • 반환 타입, 대입 타입, parameter 타입 내부의 중첩 generic type 분석
  • 임의의 깊이로 중첩되는 타입 구조를 처리하기 위해 Visitor Design Pattern을 학습하고 적용
  • InferSubstitutionViaAssignmentContextVisitor 구현
  • 다양한 generic structure에 대한 테스트 작성

JDK / External Library Nullability Models

  • 외부 Java 코드에서 nullability 정보 추출
  • javac plugin을 통해 nullability 정보를 JSON으로 직렬화
  • JSON 데이터를 astubx 형식으로 변환하는 pipeline 구현
  • NullAway에서 external model을 읽어 사용할 수 있도록 연동
  • Method type parameter, nested annotation, parsing corner case 등을 지속적으로 개선
