NullAway

Java · Static Analysis · Open Source · Compiler · JSpecify

Uber의 Java nullability 정적 분석 도구 NullAway의 기능을 확장했습니다. 대학원 연구부터 졸업 후까지 프로젝트에 참여하며 generic method 지원과 외부 라이브러리의 nullability 정보를 NullAway에서 활용하기 위한 기능을 구현했습니다.

Generic Method Type Argument Analysis

  • Generic method 호출에서 type argument의 nullability 분석 기능 구현
  • 반환 타입, 대입 타입, parameter type 내부의 중첩 generic type 분석
  • 임의의 깊이로 중첩되는 타입 구조를 처리하기 위해 Visitor Design Pattern을 학습하고 적용
  • 구현한 기능에 대한 테스트 작성 및 기존 동작과의 호환성 검증

JDK / External Library Nullability Models

  • javac plugin을 통해 외부 라이브러리 코드의 nullability 정보를 추출해 JSON 형태로 저장
  • JSON 데이터를 astubx 형식으로 변환하는 파이프라인 구현
  • 생성된 astubx 파일을 NullAway가 외부 라이브러리의 nullability 모델로 읽어 활용할 수 있도록 연동
  • Method type parameter 및 nested annotation 처리 지원, parsing corner case 수정

Rust Atomicity Violation Dynamic Analyzer

Rust · LLVM · Python · Dynamic Analysis · VS Code Extension

학부 캡스톤 프로젝트에서 2인 팀의 팀장으로, Rust concurrent 프로그램에서 발생하는 Atomicity Violation을 자동으로 탐지하는 동적 분석기를 개발했습니다. 프로그램 instrumentation부터 실행 로그 분석, 결과 시각화까지 하나의 분석 흐름으로 구현했습니다.

System Design & Implementation

  • Rust 오픈소스 프로젝트의 concurrency bug를 조사하고 Atomicity Violation 발생 패턴 정의
  • Custom LLVM Pass를 구현하여 Load, Store, Mutex 및 RwLock 연산의 실행 정보를 자동 수집
  • Thread ID, 메모리 주소, 연산 종류, 파일명 및 줄 번호를 실행 로그로 기록하도록 instrumentation 구현
  • Python Analyzer를 구현하여 실행 로그에서 Atomicity Violation 패턴 탐지
  • 탐지된 코드 위치를 VS Code에서 강조하도록 분석기와 VS Code Extension 연동

Testing & Analysis

실제 Rust 오픈소스 버그를 포함한 8개의 테스트 케이스로 분석기를 검증했습니다. 일부 버그가 탐지되지 않는 문제를 분석하여, LLVM Pass가 Rust Standard Library 내부에서는 동작하지 않아 필요한 메모리 접근 정보가 수집되지 않는 것이 원인임을 확인했습니다. 이를 통해 분석 도구의 구현뿐 아니라 관찰 가능한 범위와 한계를 검증하는 과정의 중요성을 경험했습니다.
