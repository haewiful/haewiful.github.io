OPEN SOURCE · STATIC ANALYSIS

NullAway

Uber에서 개발한 Java 정적 분석 도구 NullAway의 기능 개선에 참여했습니다.

NullAway는 컴파일 단계에서 Null Pointer Exception이 발생할 수 있는 코드를 검사하는 도구입니다.

기존에 지원이 부족했던 제네릭 메서드에 대한 Nullability 검사를 구현하고, JSpecify 표준에 맞게 타입 인자를 분석하도록 개선했습니다.

특히 명시적으로 타입 인자를 전달하지 않는 메서드 호출에서도 대입문의 타입 정보를 활용하여 타입 인자를 추론하는 기능을 구현했습니다.

또한 다양한 제네릭 메서드 호출 상황에 대한 테스트 케이스를 작성하고, Nullability 위반에 대한 오류 메시지를 개선했습니다.

CAPSTONE · DYNAMIC ANALYSIS

Dynamic Atomicity Violation Detection for Rust

Rust 프로그램에서 발생하는 동시성 오류 중 하나인 Atomicity Violation을 검출하는 동적 분석 도구를 개발했습니다.

LLVM Pass를 활용하여 프로그램 실행 중 메모리 접근 정보를 기록하고, 생성된 로그를 분석하여 오류 패턴을 탐지하는 방식입니다.

프로젝트에서 Python 기반 분석 모듈 개발을 주로 담당했으며, 검출된 오류의 위치를 시각적으로 확인할 수 있도록 VS Code 확장 기능 개발에도 참여했습니다.

작성된 테스트 케이스를 통해 오류 검출 결과를 확인하고, 분석 도구의 동작을 검증했습니다.

Rust LLVM Python Dynamic Analysis Concurrency

ACADEMIC · SOFTWARE TESTING

Mutation Testing Program

소프트웨어 테스트의 효과를 평가하는 기법인 Mutation Testing을 활용한 프로그램을 구현했습니다.

원본 프로그램을 일부 변형한 Mutant를 대상으로 테스트를 수행하고, 테스트가 변형된 프로그램의 차이를 검출하는지 확인하는 과정입니다.

Bash Script와 C 프로그램을 작성하여 서로 다른 Coverage Criteria에 따른 Mutation Testing을 실행했습니다.

이 프로젝트를 통해 단순한 테스트 실행을 넘어 테스트 자체가 결함을 발견하는 데 얼마나 효과적인지 평가하는 방법을 경험했습니다.
